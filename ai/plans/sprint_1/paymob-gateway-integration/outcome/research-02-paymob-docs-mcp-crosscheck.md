## 2. Per-query findings

### Q1 `create intention API` — GOOD
Top result after overview: `paymob-docs/intention-apis/create-intention.md`. Substantive (verbatim field names from the schema JSON):
- Endpoint `"method": "POST", "path": "v1/intention/"`, headers `Authorization: Token sk_test_…`, `Content-Type: application/json`.
- Required body: `amount` (cents, number), `currency` ("must match the currency of the selected Integration ID"), `payment_methods` (array of integration IDs as integers **or names e.g. `"card"`; test/live status must match the secret key). `billing_data`: `first_name`, `last_name` required (max 50), `email` required, `phone_number`. `items[]`: `name` required (max 50), `amount` required ("sum of all item amounts must equal the total transaction amount"), `description` (max 255), `quantity`, `image`.
- Optional: `special_reference` — *"A unique reference associated with the transaction or order, returned in the transaction callback under merchant_order_id"* (example `phe4sjw11q-1xxxxxxxxx`); `extras` — *"returned in callbacks under the payment key claims object"*; `expiration` (3600); `notification_url` (*"POST … with full transaction details … Supported only with card Integration IDs … will receive the transaction callback and the card token"*); `redirection_url` (*"Supported for Card and Wallet payment methods only"*).
- Response `201`: `payment_keys[{integration, key, gateway_type, iframe_id, order_id}]`, `intention_order_id`, `id` (e.g. `pi_test_bd49bb7fb4da48cfac4ec71ab4d8c433`), `intention_detail{amount, items, currency, billing_data}`, `client_secret` (e.g. `egy_csk_test_…`), `payment_methods[{integration_id, alias, name, method_type, currency, live, use_cvc_with_moto}]`, `special_reference` (echoed), `extras{creation_extras, confirmation_extras}`, `confirmed`, `status: "intended"`, `created`, `card_detail`, `card_tokens[]`, `object: "paymentintention"`.
- Documented common errors: 404 `"Integration ID/Name does not exist in our system…"`; 400 `items.name/items.amount` "This field is required."; 400 `billing_data.phone_number` "This field is required."
