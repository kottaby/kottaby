## What was built

The transport-tier suite over the REAL wire (HTTP → gateway pipeline → scope-auth → resolver → service → PostgreSQL), mirroring `parent-link.wire.test.ts` harness conventions (`setupTestServerLifecycle()` + `testClient` + raw `fetch` for byte-shape assertions):

1. **Auth matrix (pre-resolver)** — anonymous mutation → `UNAUTHORIZED` 401 envelope; student/parent/admin mutation → `FORBIDDEN` 403 envelope (`$all` conjunction); anonymous queries → 401. Single-error envelope parity (exactly one error, expected `extensions.code`, no data leakage).
2. **Closed-input smuggle probes** — extraneous top-level input fields (`id`, `sessionId`, `teacherId`, `createdAt`, grade keys at assignment level) → `GRAPHQL_VALIDATION_FAILED` pre-resolver; unknown query fields rejected.
3. **Id-shape fuzz** — non-numeric / negative / zero / float / overflowing session ids → uniform typed denial, no 500s.
4. **Wire ≡ service payload equality** — successful submit + both reads field-identical to the service-layer return.
5. **Null-collapse byte identity** — foreign-teacher read vs nonexistent-session read → byte-identical normalized response bodies (serialize-and-compare) for BOTH queries; participant read returns the row.
6. **Domain errors at the wire** — wrong-state → `SESSION_INVALID_TRANSITION`; duplicate → `SESSION_REPORT_ALREADY_EXISTS`; validation junk → `VALIDATION`; localized copy asserted via locale keys for **en + ar**.
7. **Matrix completeness** — one assertion per cell of plan §3.4's permission matrix (8 caller classes × 3 operations).
