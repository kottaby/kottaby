## Key-name decisions

- **Wrong-state conflict**: `ConflictError("SESSION_INVALID_TRANSITION", t.sessionInvalidTransition)` — `sessionInvalidTransition` EXISTS in `shared/locale/types/errors/labels.ts` (line 141) and is the exact key the sibling transition/confirmation classifiers throw with; no fallback needed.
- **Gate miss / foreign teacher**: identical `NotFoundError("SESSION", t.sessionNotFound)` (oracle-safe), code `SESSION_NOT_FOUND`.
- **Report duplicate**: `ConflictError("SESSION_REPORT_ALREADY_EXISTS", t.sessionReportAlreadyExists)` keyed by `isUniqueViolation` (code `23505` cause-chain walk).
- **Homework duplicate**: same code/key, keyed by `isUniqueViolation(err) && uniqueViolationOnConstraint(err, "home_work_session_id_unique")` (constraint-name check on the cause chain).
- **Grade-race conflict**: `ConflictError(t.homeworkAlreadyGraded)` (default `CONFLICT` code).
- **Status comparison**: `probe.status !== SESSION_COMPLETED_STATUS` — the exported string-identity widening const from `session-lifecycle.guards.ts` (the house pattern that passes `no-unsafe-enum-comparison`; `SessionStatus.Completed` direct comparison is oxlint-flagged). `SessionStatus` itself is therefore NOT imported here.
- **Governance**: `assertActorGovernanceClean(teacherUserId, t, outerTx)` — signature takes optional `tx` third (mirrors `createSession`'s call with `outerTx`); it does its own denial logging.
- **Denial logs** (one per path, `{code, entity, entityId}`): gate miss → `"session"`; wrong state → `"session"`; report dup → `"reports"`; grade race → `"home_work"` (entityId = target homework id); assignment dup → `"home_work"`. Nothing on success.
