## Route shape (plan §4.2 contract rows, verbatim compliance)

- **Method**: GET only — only `GET` is exported; Next.js answers other verbs with its own 405.
- **Mode gates FIRST**: bare `new Response(null, { status: 404 })` — no envelope, no code, no `requestId`, no `content-type` (asserted) — unless BOTH env gates hold; gates are evaluated before any auth work (fail-closed ordering pinned by tests that pass credentials at a disabled surface).
- **Auth**: `Authorization: Bearer <CRON_SECRET>` only; `bearerSecretMatches` hashes both sides to fixed-length SHA-256 digests before `timingSafeEqual` (no length leak, no early exit); `secret === undefined || secret.length === 0` fails closed to the masked 401 even before the compare (empty-secret configured ⇒ 401). Query string is never consulted (pinned by a dedicated test smuggling `?secret=…&token=…`).
- **Delegate**: `SubscriptionExpiryService.expireDue()` — production path omits `outerTx` (the sweep opens its own transaction; SAVEPOINT seam reserved for tests).
- **Success**: `apiSuccessResponse({ expired: result.expired, lanesZeroed: result.lanesZeroed }, { requestId })` — honest counts only; no row identities.
- **Failure**: `catch (error: unknown) → apiErrorResponse(error, { requestId, locale })` — masked 500 `INTERNAL_SERVER_ERROR`; the masked message never carries the raw throw text (asserted).
- **Locale**: fixed `"en"` for envelope classification only (cron callers never render localized copy).
- **No session reads, no new env keys**: only the three pre-existing `CRON_*` keys via raw `getEnv`; zero `@/backend/lib/auth` imports.
