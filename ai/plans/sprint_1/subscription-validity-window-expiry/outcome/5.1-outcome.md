- `export namespace SubscriptionExpiryService` with `expireDue(outerTx?: DBTransaction): Promise<SubscriptionExpirySweepReturnType>` — `withTransaction(outerTx, async tx => { … })`; SAVEPOINT on a caller-owned tx (test path), own transaction in production.

- NULL `balance_lane` = configuration gap: the row's flip STANDS, the zeroing is skipped with one correlated `logger.warn` (ids only) — fail-safe, not fail-silent.
- Zeroing walk: (student, lane) pairs deduped into an insertion-ordered map, then walked SEQUENTIALLY via a recursive helper (the session-sweeper refund-walk shape; each await yields, recursion only across awaits) — each pair is ONE guarded statement on the SAME transaction; `lanesZeroed` counts only `true` returns.
- Return `{ expired: due.length, lanesZeroed }` — counts only, no row ids; honest under replay and under a lost concurrency race.
- NO notification fan-out, NO `audit_logs` writes (system-scope/actor-less: no recipient, no actor — observability is structured logs + counts).
- `logger` imported from `@/backend/lib/logger` only; `logger.error` reserved for anomalies (unreachable-invariant aborts), `logger.debug` for the empty sweep, `logger.warn` for the config-gap skip. No `console.*`, no PII — log contexts carry ids only.
