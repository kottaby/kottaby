## Consequence for Implementation

- Pre-state classification for INV-S6 release: the transitioned row itself carries `status` AFTER the write; the pre-state is recoverable from the *legal-set* shape of each writer (`completeSessionOnce`/`resolveDisputeCompleteOnce` only ever fire from `started`-provenance rows by predicate) and, for `cancelSession`/`resolveDispute(Cancel)`, from `startedAt IS NOT NULL` (the row's own stamp — a `scheduled` cancel never has one). This is the "prior state classification via caller flow" the plan cites — no new probe write-path read needed beyond `startedAt`.
