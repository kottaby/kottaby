## Summary

Created `backend/graphql/test/session-booking-balance.test.ts` — the executable transport pin that closes gap G3. It drives `createSession` through the `setupTestServerLifecycle` + `testClient`/Apollo harness as a zero-balance student (trial lane = 0 AND intent lane = 0) and asserts `errors[0].extensions.code === "INSUFFICIENT_BALANCE"` with the localized `insufficientBalance` message resolved from `getServerTranslations("en").errorsTranslations` — the first `INSUFFICIENT_BALANCE` hit in `backend/graphql/test/`.

Six tests across four describes:
1. **Zero-balance denial** — empty student vs certified teacher → `INSUFFICIENT_BALANCE`, first error item's `message` exactly the localized bundle value.
2. **Zero side-effect rows** — `sessions` row-count delta for the fixture teacher/student pair stays 0 across the denial, and the student's `session_request_idempotency` claims stay 0 (the rolled-back booking burns no key).
3. **Funded-lane success control** — a funded student (hifz = 1) books the same teacher over the same wire → live `Session` payload (Scheduled, feeHeld true, wire-shaped id strings) — the denial is balance-specific, never a transport artifact. The created session id is registered for FK-safe hard-delete cleanup.
4. **Unauthenticated probe** — anonymous `testClient` call → `UNAUTHORIZED` (pre-resolver 401).
5. **Teacher-role BFLA probe** — certified teacher call → `FORBIDDEN` (the explicit `$all { authenticated, role: [Student] }` leg; no role bypass).
6. **SEC payload probe** — the serialized `INSUFFICIENT_BALANCE` denial container carries none of `balanceTrial|balanceHifz|balanceTajweed|balanceReviews` (the denial channel exposes the localized message + `extensions.code` only).
