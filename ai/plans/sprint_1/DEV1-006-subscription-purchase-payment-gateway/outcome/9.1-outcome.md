## Decision log

1. **Entity renamed `Subscription` → `StudentSubscription` on the wire (plan deviation, forced).** Empirical proof: with the object named `Subscription`, the built schema exposed `getSubscriptionType() === "Subscription"` — graphql-js infers operation roots from the type map by default name when the builder declares none, so the entity became a live subscription root (fields would be executable as subscription events; `sdl-static-assertions.test.ts` red). The no-GraphQL-subscription invariant (WebSocket sidecar owns realtime) is load-bearing, so the name is reserved. Canonical backend typing is untouched (`SubscriptionReturnType`); backend service/resolver code (9.2) keeps `SubscriptionReturnType`/`PurchaseSubscriptionReturnType` everywhere — only the GraphQL type name differs. REQ-060's substance (ONE canonical object per entity, from `@/backend/types`, `id` exposed) holds; REQ-063's `mySubscriptions` becomes `[StudentSubscription!]!` (carry-forward for 9.2/9.3).
2. **"NO Subscription root" pin re-tiered.** The artifact-side AST check ("no ObjectTypeDefinition named `Subscription`") conflated the entity name with rootness; with default root naming the SDL text cannot distinguish a plain object from a root. It was replaced by: artifact tier — no schema-definition entry may declare a `subscription:` root (textually decidable half); built-schema tier (new test in schema-surface.test.ts) — `graphQLSchema.getSubscriptionType()` must be null (the canonical half). Intent unchanged, enforcement now correct; mirrors the file's own lexical→AST retirement precedent.
3. **schema-surface.test.ts freeze pins refreshed.** Added `DEV1_006_ENUMS` (4 enums) + `DEV1_006_TYPE_NAMES` (4 objects). The suite was ALREADY RED at baseline (stash-roundtrip proven before any of my edits): 4 tests failing on prior-ticket surfaces never reconciled (admin audit trail, admin broadcast, teacher cold-start certification, parent-child link). Reconciled as a documented one-time re-anchoring (the file's own DEV3-016 idiom): `RECONCILED_*` constants pin `adminAuditLogs`; `myIncoming/MyOutgoingParentLinkRequests`; `adminBroadcastNotification`, `adminCertifyTeacherColdStart`, `cancelParentLinkRequest`, `requestParentChildLink`, `respondToParentLinkRequest`; enums `BroadcastAudienceType`, `LinkStatus`; types `AdminAuditLogEntry`, `AdminAuditLogFiltersInput`, `AdminAuditLogPage`, `AdminBroadcastNotificationInput`, `BroadcastAudienceInput`, `IncomingParentLinkRequest`, `OutgoingParentLinkRequest`. Suite now 42 pass / 0 fail.
4. **Frontend literals carry explicit `undefined`, never `null`** — `undefined` is dropped by JSON serialization (field absent on the wire), preserving exact pre-9.1 semantics for both catalog mutations until the lane select lands.
5. **Enum wire names are the TS keys verbatim** (`Mock`, `OfflineCash`, `Hifz`, `Tajweed`, `Reviews`, …) per the repo's Pothos convention (TransactionType/SessionStatus precedent) — the plan sketch's `HIFZ`-style guess does not apply.
