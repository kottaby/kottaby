**Behavior contracts pinned by tests:**
- `listForAdmin` normalizes the window exactly like the participant lists (`page < 1 → 1`; `pageSize` outside 1..50 → 25) BEFORE any database work; filters are AND-ed, absent members drop out (never error); the creation window is half-open over `created_at` (`>= dateFrom`, `< dateTo` — zero-width ⇒ empty); `total` is computed from the SAME predicate builder as the rows (coherence by construction); `needsAttention` = disputed OR (scheduled AND lapsed confirmation deadline) — presentation-only.
- Guards return the updated row or `null` (zero rows matched: unknown id, terminal, disputed, replayed). The caller classifies a miss via the existing `findTransitionProbe` cold probe (the `SESSION_NOT_FOUND` vs `SESSION_INVALID_TRANSITION` split already pinned by 0.2/1.3).
- All guards stamp `updatedAt` from ONE captured instant; escrow/hold columns, confirmation deadline, and reasons are structurally absent from every SET clause.
- Eligibility matrices (D-03 canon, binding F-3 applied): reschedule `scheduled|started`; cancel `scheduled|started` (`disputed` refused with zero writes); reassign `scheduled` only.
