### 2.1 `ParentLinkRequestService` (item 1)

```ts
export async function respondToLinkRequest(
  requestId: number, accept: boolean, studentActorId: number, locale: string,
  outerTx?: DBTransaction, options?: NotificationEngineCallOptions
): Promise<IncomingParentLinkRequestReturnType>
```
- **Ordering:** `requireActor(studentActorId, UserRole.Student, locale, outerTx, /* enforceGovernance */ true)` runs BEFORE `withTransaction(outerTx, …)` opens (governance pre-tx, DEV1-014 D9a).
- **One captured `now`** inside the unit drives claim stamp + liveness.

### 2.2 Helpers (item 2) — see §4 for the frozen vocabulary

- `classifyUnclaimableRequest(requestId: number, actorId: number, direction: "student" | "parent", tx: DBTransaction): Promise<UnclaimableDenial>` — `findById` oracle; missing ≡ foreign → `"not-found"`; non-pending → `"already-resolved"`; pending-but-unclaimable → `"expired"`. Status passes `toCanonicalLinkStatus` (fail-closed) first.
- `raiseUnclaimableDenial(requestId, denial, locale, outerTx): Promise<never>` — ALWAYS throws; exactly ONE `logDomainError` per denial; expired arm FIRST folds `markExpiredIfPending` in a unit that survives the throw.
- `requireActor(actorId: number, expectedRole: UserRole, locale: string, tx: DBQueryExecutor | undefined, enforceGovernance: boolean): Promise<UserSelectType>` — non-positive/missing → `UnauthorizedError(t.unauthorized)`; role mismatch → `ForbiddenError(t.forbidden)`; `enforceGovernance && (isDeleted || isBlocked || suspended)` → SAME constant `ForbiddenError(t.forbidden)` (three governed arms indistinguishable). Every denial logs exactly ONE bounded `logDomainError` (`entity: "users"`). NOTE: the helpers file is deliberately NOT re-exported by the parents barrel — tests import via `@/backend/services/parents/parent-link-request.helpers` only when a cell genuinely needs it (the DEV1-014 suites exercise them through the service).

### 2.3 Repository (item 3)

- `respondToPendingForStudent(requestId, studentId, target: LinkStatus.Confirmed | LinkStatus.Rejected, now: Date, tx: DBTransaction): Promise<ParentLinkRequestSelectType | null>` — ONE guarded UPDATE: `id ∧ student_id ∧ status='pending' ∧ expires_at > now` → `.set({ status: target, respondedAt: now })` → `RETURNING *`; `null` on zero rows (nonexistent ≡ foreign ≡ resolved ≡ expired — indistinguishable).
- `expireSiblingPendingsForStudent(studentId, winnerRequestId, tx): Promise<number>` — `student_id ∧ status='pending' ∧ id <> winner` → `expired`, returns count.
- `markExpiredIfPending(requestId, tx): Promise<void>` — idempotent-by-predicate fold; `responded_at` left NULL.
- `listIncomingForStudent(studentId, tx?: DBQueryExecutor): Promise<IncomingParentLinkRequestRow[]>` — dual executor (Drizzle select on tx / raw parameterized SQL via `queryDb` standalone), `JOIN users u ON u.id = parent_id` for `parentFullName`, `ORDER BY created_at DESC, id DESC LIMIT 50`.
- `findIncomingRowById(requestId, tx?: DBQueryExecutor): Promise<IncomingParentLinkRequestRow | null>` — same projection, LIMIT 1.
- Locking posture: predicate+mutation in the same statement; NO `SELECT FOR UPDATE`, NO advisory locks (file header L8–15).

### 2.4 GraphQL surface (item 5)
