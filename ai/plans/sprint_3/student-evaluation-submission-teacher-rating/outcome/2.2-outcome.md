## 3. RED-state design decision (compile-clean RED)

A static import of the future service cannot compile (module absent ⇒ TS2307), which would fail the
quality loop instead of yielding a runtime RED. Following the task's documented fallback, the journey
resolves the service **through the existing teachers barrel** (`@/backend/services/teachers`) with the
service contract declared test-side, an `as unknown as` projection (no `any`), and an explicit
undefined-guard that throws the RED message verbatim:

```
student-to-teacher rating service not implemented yet: StudentEvaluationService is missing from @/backend/services/teachers
```

Nothing is stubbed or mocked: when the real namespace is exported, every leg calls it unmodified through
the same seam. The denial probes wrap calls in the try/catch helper, so under RED they surface this exact
message inside the `toBeInstanceOf(DomainError)` failure — the RED is attributable, not incidental.
