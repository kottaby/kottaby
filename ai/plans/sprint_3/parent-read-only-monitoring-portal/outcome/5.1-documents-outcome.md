## Summary

Created the shared `TypedDocumentNode` operations backing the parent
read-only monitoring portal: five named `query` documents exported from
`frontend/graphql/sharedDocuments/parents/parent-monitoring.documents.ts`,
barrel-registered in the same directory's `index.ts`, and lock-pinned by
a co-located structural test (`parent-monitoring.documents.test.ts`).
The documents are consumed by task 5.3's portal views via `useQuery`
from `@apollo/client/react` (NO `useLazyQuery` anywhere — documents
only, never hooks).

Every document carries `id` FIRST on every entity-shaped object
selection (`ParentLinkedChild`, `ParentAttendanceEntry`,
`ParentReportEntry`, `ParentHomeworkEntry`) so Apollo Client normalizes
them into cache entries. The three page wrappers
(`ParentAttendancePage`, `ParentReportPage`, `ParentHomeworkPage`) and
the three composite value objects (`ParentHomeworkTrack`,
`ParentHomeworkPosition`, `ParentChildProgress`) carry no `id` — they
are registered with `keyFields: false` in
`frontend/providers/apollo/apolloCache.ts` (task 5.4, complete) and are
embedded value types replaced wholesale on refetch.

The variable surface is BOLA-tight: the four per-student reads send
ONLY `studentId` + optional `page` / `pageSize` (REQ-024.4); the list
query is zero-argument (caller identity IS the read scope). NO
parent/actor/user id, role, auth, or token hint exists anywhere in any
document body — parent identity is ALWAYS derived server-side from the
authenticated caller (`ctx.user.id`).

Codegen refresh ran cleanly: `bun run generate:gqlSchema` produced a
byte-identical SDL (task 3.3 already locked the five new query fields
and the ten new object types); `bun codegen` extended
`frontend/graphql/generated/gql/graphql.ts` by +70 lines with the five
`{OperationName}Query` types, the five
`{OperationName}QueryVariables` types, and the ten nested
`{OperationName}_{field}[_{subField}]` extracted field types. The
committed codegen output is the only build-affecting artifact of this
task — no env vars, no infra changes (REQ-030.4 honored).
