## Testing Discipline

Per `backend/services/AGENTS.md` (service-test rules) and the 2.4 outcome's
carry-forward: the persistence seam is MOCKED via `spyOn` on every repository
the service consumes (`StudentRepository`, `UserRepository`,
`SessionRepository`, `ReportRepository`, `HomeWorkRepository`,
`ProgressRepository`). ZERO real rows are written. `runInRollback` supplies
the transactional `tx` that the service's `withTransaction(outerTx, ...)`
joins as a SAVEPOINT — denial throws inside the savepoint surface to the test
cleanly without aborting the outer tx.

All translated-message assertions compute the expected copy through
`getServerTranslations(locale).errorsTranslations.forbidden` — never raw
strings. Denial copy is asserted for BOTH `en` and `ar`.

Spy lifecycle is managed via a `trackedSpies` array + `afterEach` restoration
(matches the `parent-link-request.helpers.test.ts` convention). The
`silenceDomainLog()` helper installs a no-op `logDomainError` spy so denial
tests don't pollute the test runner's stderr.

#### Tier 4 — security (denial oracle + BOLA + gate-before-read)

**Denial oracle (REQ-022 pin):** every per-student method (`getChildProgress`,
`listChildSessions`, `listChildReports`, `listChildHomework`) × every denial
cause (malformed id, missing row, foreign id, never-linked id, severed child)
is asserted:
- `ForbiddenError` with code `FORBIDDEN`.
- Localized message equal to `getServerTranslations(locale).errorsTranslations.forbidden`
  for BOTH `en` and `ar` locales.
- Exactly ONE bounded `logDomainError` per denial, whose context bag is
  exactly `{ code: "FORBIDDEN", entity: "students", entityId: <studentId>,
  locale }` — ZERO child fields (`parentId`, `fullName`, `handshakeCode`,
  etc. never appear in the context bag).

That is **4 methods × 5 causes × 2 locales = 40 per-cell tests** + an explicit
**oracle-uniformity test** that runs all 20 (method × cause) cells under `en`
via `Promise.all` and asserts every cell produces a byte-identical denial
fingerprint (`{ code, message }` JSON string).

**BOLA (token-role denial):** a non-parent actor (admin/teacher/student) is
rejected by `requireActor(..., UserRole.Parent, ..., false)` with
`ForbiddenError` BEFORE any per-student transaction opens. Proven via
gate-before-read spy assertions: the downstream repo calls
(`listLinkedChildrenByParentId`, `ProgressRepository.countForStudent`,
`SessionRepository.listForStudent`, `ReportRepository.listForStudent`,
`HomeWorkRepository.listForStudent`) record ZERO invocations while the
gate's own `UserRepository.findById` records its sanctioned actor read.

**Gate-before-read call ordering:** `requireLinkedChild` (which calls
`StudentRepository.findById`) fires BEFORE any downstream data read
(`ProgressRepository.countForStudent`, `HomeWorkRepository.findLatestByStudentId`,
`SessionRepository.listForStudent`, `countForStudent`). Proven via
`mock.invocationCallOrder` assertions — the gate's `StudentRepository.findById`
call order is strictly less than every downstream read's call order.

**BFLA defense-in-depth (direct `requireActor` coverage):** teacher-role and
student-role actors are rejected with `ForbiddenError` carrying the localized
`forbidden` copy (asserted for both `en` and `ar`). A parent-role actor with
governance flags set (`isDeleted: true`) is ALLOWED on the relaxed read path
(`enforceGovernance: false`) — the governance arm is disabled so a
governed-but-not-deleted parent's self-scoped reads stay visible.

### 6.2.SEC — Security & Tenancy Audit

**Denial responses carry ZERO child fields:** the `deny()` closure in
`requireLinkedChild` is the ONLY log site on the denial path. Its context bag
is exactly `{ code: "FORBIDDEN", entity: "students", entityId: <studentId>,
locale }`. Verified by:
- A dedicated test that asserts `Object.keys(context).toSorted(compareStrings)`
  equals exactly `["code", "entity", "entityId", "locale"]`.
- The per-cell tests that assert the message matches
  `errorsTranslations.forbidden` — no child fields leak into the message.

**Exactly ONE bounded `logDomainError` per denial:** verified by
`expect(logSpy).toHaveBeenCalledTimes(1)` on every denial arm. The `deny()`
closure logs once and throws immediately — no second log can run.

**BOPLA (output projection):** closed-shape assertions on every projection
mapper — `Object.keys(entry).toSorted(compareStrings)` matches the canonical
field list. `updatedAt` is silently dropped at the mapping seam (asserted
absent). No `teacherId`, `fee`, `heldBalanceLane`, `cancelReason`,
`disputeReason`, `confirmationDeadline` fields ever appear in the projection.

**BOLA:** identity flows ONLY from the `parentActorId` parameter (which arrives
from `ctx.user.id` at the GraphQL layer). The `studentId` is validated against
the caller's grant (`students.parentId === parentActorId`) BEFORE any data
read — proven by the gate-before-read call ordering tests.

**BFLA:** `requireActor(..., UserRole.Parent, ..., false)` rejects non-parent
roles before the per-student transaction opens — proven by the BOLA tests
(downstream repo calls record ZERO invocations on a non-parent actor).
