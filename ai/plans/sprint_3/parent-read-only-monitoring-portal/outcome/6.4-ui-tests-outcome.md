## Test Bugs Fixed

### Bug 1 — relative import path in `ParentChildrenRootContainer.test.tsx`

The prior subagent's suite imported helpers via `./helpers` (relative).
AGENTS.md mandates `@/` path aliases for all imports. Fixed by
retargeting to `@/test/ui/components/parent/monitoring/helpers`.

### Bug 2 + Bug 3 — `.length).toBe(N)` pattern in `ParentChildrenRootContainer.test.tsx`

Two assertions used `expect(screen.getAllByText(...).length).toBe(2)`.
The `sonarjs/prefer-specific-assertions` rule requires
`expect(...).toHaveLength(N)` for better failure reporting on any
object with a numeric `length` property. Fixed both occurrences.

## New Suite — `ParentChildTabs.test.tsx`

### Coverage map

The suite covers the FIVE portal tab components directly (not through
the `ParentChildDetailContainer` host — mounting tabs directly isolates
the tab's own state matrix from the container's linked-children query):

- **ProgressTab** — `parentChildProgressQueryDocument`, `{ studentId }` variables.
- **AttendanceTab** — `parentChildSessionsQueryDocument`, `{ studentId, page, pageSize }` variables.
- **ReportsTab** — `parentChildReportsQueryDocument`, `{ studentId, page, pageSize }` variables.
- **HomeworkTab** — `parentChildHomeworkQueryDocument`, `{ studentId, page, pageSize }` variables.
- **EvaluationsTab** — shares `parentChildReportsQueryDocument` with ReportsTab (two client-side projections of the same rows).

Each tab × each locale (`ar` + `en`) × 4 states = 40 tests, plus 1
per-child re-keying proof = 41 tests total.

### State matrix per tab

| State | testid hook | Assertion |
|---|---|---|
| loading | `parent-<tab>-loading` | `aria-busy="true"`; section heading renders; no list/empty |
| empty | `parent-<tab>-empty` | localized empty title renders; no list/skeleton |
| data | `parent-<tab>-list` | `aria-label` = section title; row-count heading renders; per-row cards |
| FORBIDDEN | (PermissionDeniedFallback) | `errors.forbiddenRole` + `errors.forbidden` render; no list/skeleton; raw transport message NEVER renders |

### Per-child re-keying proof

A test-only `ProgressTabRekeyWrapper` flips the `studentId` prop on
click. The test verifies:

1. The initial child's `progressRowCount` heading renders first.
2. After the re-key click, the foreign child's `progressRowCount` heading
   renders (NOT the initial child's — Apollo cache isolation holds).
3. Both queries carried their OWN `studentId` —
   `traffic.capturedVariables` contains both
   `{ studentId: ACTIVE_STUDENT_ID }` and `{ studentId: FOREIGN_STUDENT_ID }`.
4. ZERO mutation operations crossed the wire (read-only posture).

## Testing Discipline

Per `test/ui/AGENTS.md` (component-test rules) and the carry-forward
from task 5.3:

- **Happy DOM + mocked Apollo (NO server)** — the suites mount
  components under a `MockedProvider` with a RECORDING `ApolloLink`
  chained in front of a `MockLink`. The recording link captures every
  operation's name + variables before forwarding to the mock link so
  the wire-traffic proofs read real link traffic.
- **State matrix is Tier 1** — every rendering branch (loading, empty,
  data, FORBIDDEN) is exercised per tab. No dead arms.
- **RTL render arm for `ar`** — the `for (const locale of ["ar", "en"])`
  loop drives every tab × state across BOTH locales. The `renderPortal`
  helper passes the locale to `renderWithWrapper` which sets up the
  RTL directionality + locale provider.
- **Translation discipline** — assertions reference ONLY the preloaded
  label objects resolved through
  `ParentMonitoring.getLabels(getTranslations(locale))` and
  `Errors.getLabels(getTranslations(locale))`. ZERO hardcoded
  Arabic/English copy lives in the suite.
- **Read-only posture (REQ-023.4)** — every render mounts the
  recording link; `expectZeroMutations(traffic)` inspects real link
  traffic and asserts ZERO mutation operations crossed the wire.
- **Mocks typed against generated documents** — the helpers' fixture
  factories return CLOSED shapes typed against the codegen-emitted
  `*Query_*_items` extracted-field types — never `Partial<...>`
  stand-ins.
- **No snapshot-brittleness** — every assertion is structural (testid
  presence, text content, aria attributes). No `toMatchInlineSnapshot` /
  `toMatchSnapshot` calls.
- **Network settle** — `settleNetwork()` (60ms timeout) lets any
  forbidden in-flight activity surface before asserting zero mutations.
- **Cleanup** — `afterEach` calls `cleanup()` (Testing Library) +
  `resetNavigationCalls()` (resets the `testNavigationState` mock
  counters).

#### Tier 1 — the state matrix IS Tier 1

- **5 tabs × 4 states × 2 locales = 40 tests** — every tab's loading
  skeleton, empty state, data list, and FORBIDDEN denial surface is
  asserted in BOTH `ar` (RTL) and `en` (LTR).
- **Root container × 9 states × 2 locales = 18 tests** — cold load
  skeleton, zero-children empty state + handshake CTA, loaded list with
  per-child cards, card-click navigation, auto-replace URL-param
  behavior, FORBIDDEN/UNAUTHORIZED denial, generic transport failure
  with retry.

#### Tier 2 — boundary arms

- **Empty `?student=` prop AND zero children → NO auto-replace** (the
  auto-select guard prevents the replace from firing on the empty
  branch).
- **Empty `?student=` prop AND ≥1 child → auto-replace fires** (the
  first child's detail URL is the destination).
- **`?student=` present → no auto-replace** (the param signals explicit
  list browsing).
- **Per-child re-keying** — switching `studentId` re-issues the query
  with the new id; the foreign child's rows never appear under the
  initial child's id (Apollo cache isolation proof).
- **Raw transport message NEVER renders** — the `RAW_TRANSPORT_MESSAGE_SENTINEL`
  assertion verifies the server's raw error message (which carries the
  error code) never reaches the DOM. The denial copy is the localized
  namespace string.

#### Tier 3 — chaos / concurrent

- N/A at the component tier — the mocked Apollo provider serializes
  operations deterministically. Concurrent-mixed-calls coverage lives
  in the service tests (task 6.2) and wire tests (task 6.3).

#### Tier 4 — security

- **ZERO mutations on the wire (REQ-023.4)** — every render mounts the
  recording link; `expectZeroMutations(traffic)` asserts the recorded
  operations carry ZERO mutations. The portal is a pure read surface —
  the read-only posture is structurally enforced by the absence of
  mutation documents on the wire.
- **Denied states render zero child data** — the FORBIDDEN denial
  surface (`PermissionDeniedFallback`) replaces the tab content; no
  list, no skeleton, no child fields render.
- **Server error messages never rendered raw** — the
  `RAW_TRANSPORT_MESSAGE_SENTINEL` is asserted absent from the DOM on
  every denial arm.
