## 2026-09-15 - Directory Search Input Clear Affordance Pattern
**Learning:** Hidden-label `TextField` components used for directory search filtering benefit from a conditional `endAdornment` clear button when `value` is present, combining `IconButton`, `Tooltip`, `aria-label`, and `focusVisibleRingSx`.
**Action:** When enhancing search or filter inputs across admin or directory surfaces, ensure non-empty inputs render a clear action with `focusVisibleRingSx` and localized or accessible `aria-label`/`Tooltip` title.
